## 🛠 作品 · Projects

### 📚 [漫画格式转换 · Comic Converter](https://github.com/boyeye/comic-converter-macos)

在 CBZ、CBR、CB7、CBT、PDF、EPUB、MOBI、AZW3 之间转换，适合把 Kindle 的 MOBI/AZW3 漫画转回 CBZ。JPEG/PNG 页面原样复制，不重新压缩。支持批量转换和批量命名，有图形界面，也有 `comicconv` 命令行。

Convert comics between CBZ, CBR, PDF, EPUB, MOBI, AZW3 and more. JPEG/PNG pages are copied as-is. GUI and command line.

### 📖 [Markdown 阅读器 · Markdown Reader](https://github.com/boyeye/markdown-reader-macos)

离线阅读 Markdown 文件，支持标签页、目录大纲、代码高亮、相对路径本地图片和 PDF 导出。只读，不修改源文件。

An offline, read-only Markdown viewer with tabs, outline, syntax highlighting and PDF export.
